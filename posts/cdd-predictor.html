Hypothesis CDD Predictor

A web app that drafts the hypothesis tree for a commercial due diligence engagement — MECE-checked scenarios, expert profiles, and confirm-or-kill evidence, generated in one pass.

June 2026 Open source Built solo · Flask + Claude API

What it is

Every commercial due diligence (CDD) engagement starts the same way: a consulting team turns a vague client question into a structured issue tree — the key question at the top, five to seven testable scenarios beneath it, and the sub-hypotheses each one has to survive. That skeleton-building phase is manual, repetitive, and always due yesterday.

Hypothesis CDD Predictor automates it. You give it the engagement context — the reference company, what the client wants to learn, and the screening questions you'd put to an expert — and it returns a full, ranked hypothesis tree: an issue statement, value-driver scenarios with hypotheses and sub-hypotheses, MECE validation on each branch, and probability estimates across the scenario set.

How it works

01
Frame
Synthesizes the CDD issue statement from the project context and generates 5–7 scenarios grounded in value drivers: market dynamics, operating model, competition, growth, and risk.
02
Validate & rank
Checks every scenario against MECE principles, extracts trigger keywords from your screening questions, and ranks scenarios by how strongly the signals match.
03
Test
Attaches suggested expert profiles to each branch, each paired with the evidence that would confirm the hypothesis — and the evidence that would kill it.

Features

  • Interactive hypothesis tree
    A clickable SVG hierarchy from issue to scenarios to sub-hypotheses, with each scenario's "so what" logic stated in plain language.
  • Explore & expand
    Confirm a sub-hypothesis and the tool generates the next depth of the tree — new sub-sub-hypotheses with fresh expert recommendations — so the tree grows with the engagement.
  • Your judgement stays in the loop
    Accept or reject suggested experts, inject your own custom hypotheses (sub-hypotheses are generated for them automatically), and export the whole tree with status tracking to CSV.

Built with a Flask backend, a vanilla-JavaScript frontend, and the Claude API for generation.
